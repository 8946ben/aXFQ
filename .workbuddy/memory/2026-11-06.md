### 三个踩过的坑（重要，复用时别再踩）
1. WorkBuddy / Claude Code 宿主设了 `ELECTRON_RUN_AS_NODE=1`，Electron 会退化成纯 Node，`require('electron')` 报 MODULE_NOT_FOUND。启动器必须 `delete env.ELECTRON_RUN_AS_NODE`（clawd 的 launch.js 注释里也写了）。
2. Electron 20+ 默认沙箱化 renderer，沙箱 preload 里 `require('path')` 不可用 → preload 整体挂掉、`window.asoul` 未定义、页面只剩静态 HTML（表现为 `<img alt>` 文字）。窗口 webPreferences 需 `sandbox:false`（保留 contextIsolation）。
3. `file://` 页面写 CSP `script-src 'self'` / `img-src 'self'`，因为 opaque origin 会把本地脚本和图片一起挡掉。本地应用别加 CSP（内容全自写、无远程加载）。

## 番茄钟简化改版（同日下午）

- **表盘拖动设时长**：面板大圆环变成可拖表盘，`pointerAngle()` 取相对圆心角度，`pointermove` 累计**相对增量**（相邻角差，跨 ±180° 归一）。比例 6°/分钟：一圈 360° = 60 分钟，1/4 圈 = 15 分钟；上限 `DIAL_MAX_ANGLE=720`（两圈 = 120 分钟），下限 1 分钟。旋钮按 0..720 角度定位（`x=100+84·sin, y=100−84·cos`），超过一圈显示「第 N 圈」角标。运行中禁止拖动（只有暂停/未开始可调），松手即写入当前模式时长并重置计时。
- **注意**：拖动是**相对**的（从 25:00 顺时针转 1/4 圈 = 40:00），不是绝对位置映射——符合「拉一圈是 60 分钟」的表述。
- **自定义标签（settings 页）**：`state.presets[]`，每条 `{ id, label, minutes, kind:'focus'|'break', message, emote }`，上限 12 条，默认空。标签出现在番茄钟的模式按钮行，点击 `timer:action('mode','preset:<id>')` 一键套用时长；`kind` 决定完成后进入休息还是专注，也决定统计归类。
- **完成话语 + 表情**：`finishTimer()` 把话语通过 `ballWin.webContents.send('speak', …)` 发给常驻悬浮球，用 `SpeechSynthesisUtterance`（zh-CN，优先中文音色）朗读；表情走 `ball:emote`，用标签选的 emote。只发给球窗口，避免两个窗口同时朗读。
- **取消「跳过」**：只保留 开始/暂停 + 重置，IPC 的 `skip` 分支一并删除。
- **统计独立面板**：`view-stats`（齿轮右侧入口「查看统计 ›」/ 托盘 / 右键菜单进入），含今日/累计番茄与分钟、最近 7 天柱状图、最近 60 条完成记录。数据源 `state.history[]`（每完成一段 push 一条，保留 500 条），7 天图按 `history` 现算。
- **旧数据迁移**：`stats.totalMinutes` 缺失时用 `focusMinutes` 补齐，避免「累计番茄 5 / 累计分钟 0」。
- **踩坑**：`Page.captureScreenshot` 对**隐藏的** BrowserWindow 会超时，且隐藏窗口里 `getBoundingClientRect()` 可能是 0（视图 `display:none` 时更甚）。CDP 验证必须先 `openPanel()` 真把面板显示出来再量尺寸/截图。
